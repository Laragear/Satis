Laragear Repository

Private Composer repository for Laragear packages

Setup

Add to your composer.json:

{
  "repositories": [
    { "type": "composer", "url": "https://laragear.github.io/satis" }
  ]
}

Add to your auth.json (your Keygen license key as Bearer token):

{
  "bearer": {
    "api.keygen.sh": "YOUR-LICENSE-KEY"
  }
}
